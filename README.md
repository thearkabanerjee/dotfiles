# Dotfiles

My personal collection of dotfiles and configuration files for my development environment.

This repository contains the configurations I use across my setup, including:

* **Neovim** — editor configuration
* **Fastfetch** — system information configuration
* **Ghostty** — terminal configuration
* **Zsh** — shell configuration
* **Git** — Git configuration
* And other personal configuration files

These are my personal settings and may change as I customize and improve my workflow.

> Built for my setup, my workflow, and my preferences.
